# Мозгочар — уютные головоломки

Яркая русскоязычная игра с логическими задачами, памятью, математикой, поиском лишнего, цветовыми последовательностями, словами и поиском пар. Спокойный режим: без таймеров и спешки.

## Запуск
Откройте `index.html` в браузере. Для публикации на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

Аватарка игры находится в `avatar.svg`.
